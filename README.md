# Santosh Pav Bhaji Wala — GitHub Pages Website

## Upload to GitHub Pages
1. Upload `index.html` and the `images` folder to your repository.
2. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/ (root)`.
3. Open the generated GitHub Pages URL.

## Replace dish images
Every menu item is mapped to its own SVG file in `images/`. To use real food photos later, replace an SVG with a JPG/PNG using the same filename, or change the filename in the `IMG` object inside `index.html`.

The site includes the WhatsApp ordering number configured in the current version and the Google Feedback/review section.
